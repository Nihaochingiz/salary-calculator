## Калькулятор зарплаты по ТК РФ

Две версии калькулятора: веб-интерфейс и консольная.

---

### Веб-версия

#### Как запустить:

1. Сохраните три файла в одну папку:
   - `index.html`
   - `style.css`
   - `script.js`
2. Откройте файл `index.html` в любом браузере

#### Возможности:
- Два режима расчёта: «На руки → Оклад» и «Оклад → На руки»
- Выгрузка результата в MD-файл
- Минималистичный белый дизайн
- Адаптивная вёрстка
- Расположение по центру страницы

---

### Консольная версия

#### Как запустить:

1. Убедитесь, что установлен Node.js (проверьте командой `node -v`)
2. Сохраните код в файл `salary-calculator.js`
3. Запустите в терминале:
```bash
node salary-calculator.js
```

#### Что делает программа:
- Запрашивает сумму, которую хотите получать "чистыми" (на руки)
- Рассчитывает:
  - Сумму с НДФЛ (gross) - сколько просить у работодателя
  - Сам НДФЛ (13%)
- Показывает результат с форматированием
- Можно считать несколько сумм подряд
- Поддерживает пробелы при вводе (удобно вбивать "100 000")

#### Пример работы:
```
Калькулятор зарплаты по ТК РФ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Я посчитаю, сколько нужно просить у работодателя,
чтобы получать желаемую сумму на руки.

Введите сумму, которую хотите получать на руки (в рублях): 100 000

РЕЗУЛЬТАТ РАСЧЁТА:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
На руки:         100 000.00 ₽
НДФЛ (13%):      14 942.53 ₽
Просить у работодателя: 114 942.53 ₽
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

Формула расчёта: `gross = net / (1 - 0.13)`, потому что НДФЛ вычитается из полной суммы.
